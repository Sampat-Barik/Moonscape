# Typography System Fonts

The project uses the following typography hierarchy loaded via Google Fonts CDN in `index.html`:
- **Display**: Space Grotesk (Weights 400, 500, 600, 700)
- **Condensed**: Rajdhani (Weights 500, 600, 700)
- **Body**: Inter (Weights 400, 500, 600)
- **Numerical / Mono**: IBM Plex Mono (Weights 400, 500)

All fonts are open-source and licensed under the SIL Open Font License 1.1.
